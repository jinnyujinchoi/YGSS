# RAG 시스템 개선 PR — Cross-Encoder 한국어 모델 교체 및 임계값 근거 확보

## 배경

운영 중인 RAG 챗봇은 다음 두 가지 문제를 가지고 있었습니다.

1. **한국어 Q&A를 영어 Cross-Encoder로 평가** (`ms-marco-MiniLM-L-12-v2`)
   - 이 모델은 영어 MS MARCO 데이터셋으로 학습된 영어 전용 모델
   - 한국어 의미 평가가 사실상 무작위 수준으로 동작

2. **근거 없는 매직 넘버** — 임계값 4개가 코드에 하드코딩
   - `VectorRepository.java`: `if(sim < 0.45) continue;`
   - `ChatBotServiceImpl.java`: `searchAllPrefixes(..., 10)`
   - `server.py`: `score >= 6`, `filtered[:3]`

## 작업 내용

백엔드 서비스에 영향을 주지 않기 위해 **독립적인 Python 평가 프레임워크**를 구축하고 실험을 진행했습니다.

`ai/experiments/rag_eval/` 참조

### 실험 구성
- 평가 셋: 운영 chat_dummy 데이터 기반 36개 질문 (정의형/계산형/비교형/맥락형)
- 임베딩: OpenAI text-embedding-3-small (운영 동일)
- 측정 지표: Precision@K, Recall@K, F1, MRR, no-result rate, latency

### Cross-Encoder 모델 비교 결과

| 모델 | Top-3 정확도 | MRR | p95 latency |
|---|---:|---:|---:|
| ms-marco-MiniLM-L-12-v2 (현재 운영) | 41.67% | 0.282 | 41ms |
| dragonkue/bge-reranker-v2-m3-ko | 83.33% | 0.653 | 161ms |
| **Dongjin-kr/ko-reranker** ⭐ | **91.67%** | **0.745** | **164ms** |
| BAAI/bge-reranker-v2-m3 | 83.33% | 0.685 | 160ms |

### 4-parameter Grid Search 결과 (420 조합)

| 파라미터 | 현재 운영값 | 민감도 | 권장값 |
|---|---|---|---|
| bi_threshold | 0.45 | 평평 (변화 없음) | **0.45 유지** |
| bi_top_k | 10 | 10→15 미미한 상승 | **10 유지** |
| cross_threshold | 6.0 (영어 매직 넘버) | **가장 민감** (0.46 초과 시 급하락) | **0.41** |
| cross_top_n | 3 | 평평 | **3 유지** |

민감도 분석 결과 `cross_threshold`만이 유의미한 영향을 줍니다.
나머지 3개 파라미터는 현행 유지가 적절합니다.

## 권장 변경 사항

### AI 서버 (`ai/src/api/routes/server.py`) — 이미 반영됨

```python
# Cross-Encoder 모델 교체 (영어 → 한국어)
CROSS_ENCODER_MODEL = os.getenv("CROSS_ENCODER_MODEL", "Dongjin-kr/ko-reranker")

# 임계값 근거: ko_reranker F1 최대화 cutoff = 0.516, grid search 최적 = 0.41
CROSS_ENCODER_THRESHOLD = float(os.getenv("CROSS_ENCODER_THRESHOLD", "0.41"))

# top-N 환경변수화
CROSS_TOP_N = int(os.getenv("CROSS_TOP_N", "3"))
```

### 백엔드 Java — 변경 권장 (현재 코드 그대로이므로 별도 적용 필요)

**1. `VectorRepository.java` line ~84**
```java
// 현재
if(sim < 0.45) continue;

// 권장 (application.yml 외부화)
if(sim < biThreshold) continue;
```

**2. `ChatBotServiceImpl.java` line ~33**
```java
// 현재
vectorRepository.searchAllPrefixes(..., 10)

// 권장 (application.yml 외부화)
vectorRepository.searchAllPrefixes(..., biTopK)
```

**3. `application.yml` 신설 키**
```yaml
chatbot:
  bi-encoder:
    threshold: 0.45   # grid search 결과: 민감도 없음, 현행 유지
    top-k: 10         # grid search 결과: 민감도 낮음, 현행 유지
  cross-encoder:
    threshold: 0.41   # grid search 결과: 가장 민감한 파라미터
    top-n: 3          # grid search 결과: 민감도 없음, 현행 유지
```
